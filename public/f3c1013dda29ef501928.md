# 概要
- MacにUbuntuを入れてLinuxをいじれる環境を構築する
- 単純にダウンロードして開くのではなく、UTMを用いてダウンロードしたファイルを開く必要がある

# 普通にやるとエラーになる
- まずは自分のMacの動作環境を調べる
```
$ uname -m
arm64
```
- arm64版のubuntuを手に入れる
    - https://ubuntu.com/download/server/arm
- しかし、このisoファイルを直接開くとエラーになる

![image.png](https://qiita-image-store.s3.ap-northeast-1.amazonaws.com/0/3339625/ebcc91f0-fd0b-cd60-fce1-cd4aff7fc924.png)

# 解決法
UTMを用いてisoファイルを開けばよい。以下の記事を参考に、UTMを使えば環境構築ができた。
- https://envader.plus/article/66a
